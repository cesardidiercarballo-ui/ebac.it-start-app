NOTAS CRUD - Modulo 7 (SQLite)
Base de datos: todolist.db | Tabla: tareas

Antes de probar, abri Python en la terminal y me conecte usando mi database.py:
    from database import connect_db
    conn = connect_db()

C - CREATE (crear): agregar una tarea nueva a la tabla.
    conn.execute("INSERT INTO tareas (titulo) VALUES ('Estudiar SQLite')")
    conn.commit()

R - READ (leer): consultar las tareas que hay guardadas.
    conn.execute("SELECT * FROM tareas").fetchall()
    Resultado: [(1, 'Estudiar SQLite', 'pendiente', '2026-09-09 23:06:31')]

U - UPDATE (actualizar): modificar un dato de una tarea que ya existe.
    conn.execute("UPDATE tareas SET estado = 'completada' WHERE id = 1")
    conn.commit()

D - DELETE (eliminar): borrar una tarea de la tabla.
    conn.execute("INSERT INTO tareas (titulo) VALUES ('Tarea de prueba')")   (cree una segunda tarea para borrarla)
    conn.commit()
    conn.execute("DELETE FROM tareas WHERE id = 2")
    conn.commit()

Notas:
- Despues de INSERT, UPDATE o DELETE hay que hacer conn.commit() para que se guarde en el archivo.
- En UPDATE y DELETE el WHERE es clave: sin el, el cambio se aplica a todas las filas.
